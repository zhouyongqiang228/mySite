# mySite

静态个人网站，无构建依赖。运行 `python3 -m http.server 5174` 后，访问
`http://localhost:5174/#skills` 查看技能球。

仅保留「光合生长」配色。47 个最终技能与经验节点均匀分布在三维球面上，球体约 42 秒旋转一圈；相邻节点通过球面曲线连接，微光沿曲线流动。没有分类标题、点击展开、分页、筛选或点击暂停。

- `skill-data.js`：原始技能目录及介绍，渲染时自动提取最终条目。
- `skill-tree.js`：Fibonacci 球面分布、透视投影、旋转、光点、深度排序和标签避让。
- `skill-tree.css`：最大 760px 的紧凑组件与响应式标签。
- `index.html`：`#skills` 为组件容器。

节点按前后深度改变大小与亮度；所有文字始终正向朝向读者，后方标签逐渐转到前方，无需点击。轻量避让与引导线减少文字拥挤，全部节点保留在 DOM 和无障碍列表中。

无需 WebGL 或第三方库。Canvas 绘制球面与光点，HTML 显示标签。减少动态效果偏好下保持静止；离屏或页面隐藏时暂停动画，返回后继续旋转。Canvas 不可用时仍显示技能标签；禁用 JavaScript 时显示静态技能清单。
