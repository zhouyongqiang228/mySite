# mySite

静态个人网站，无构建依赖。运行 `python3 -m http.server 5173` 后，访问
`http://localhost:5173/#skills` 查看完整技能树。

技能树只保留「光合生长」：微光枝干、流动光点和底部透视圆环。医学、AI 模型、开发及其所有子分支连接在同一棵树上，47 个技能与经验条目一次性全部展开。没有风格切换、筛选、分页、点击展开或详情面板，也不会读取旧主题偏好。

- `skill-data.js`：技能目录及介绍。保持现有层级，向医学、AI 模型或开发的分类中添加技能条目；每个条目使用唯一 `id`、`name`、`description`。
- `skill-tree.js`：完整树布局、连线、微光动画。桌面左右分布，窄屏纵向排列，所有标签都保留；统计和画布高度根据条目数量自动计算。
- `skill-tree.css`：光合生长样式及响应式布局。
- `index.html`：`#skills` 为组件容器。

无需 WebGL 或第三方库。使用 Canvas 绘制枝干与光点，HTML 呈现全部文字，固定标签位置以便阅读。窄屏随页面自然滚动，无需任何展开操作。减少动态效果偏好下保持静止，离屏或页面隐藏时停止组件动画。Canvas 不可用时仍保留完整文字；禁用 JavaScript 时显示静态技能清单。
