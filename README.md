# Alex 的个人求职网站

以医学 AI 软件开发为主要求职方向，同时展示企业业务自动化顾问、AI Agent、游戏与跨平台软件开发的能力匹配。纯 HTML、CSS、JavaScript，无构建依赖。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 5174
```

访问 `http://localhost:5174/`。若端口已有预览服务，直接打开即可。主样式带 `?v=9`、其余页面资源带 `?v=8` 版本标记，以避免旧样式缓存；后续更新资源时可同步修改版本号。

## 页面内容

- 首屏：医学 AI 求职定位和旋转技能球。
- 求职方向：医学 AI、企业自动化、Agent、游戏与跨平台软件。
- 工作经历：按年份倒序展示三段示例公司、职位、职责与技术标签。
- 项目经验：工具与平台、图像与数据、引擎与应用。
- 技术能力、工作思路、个人介绍、联系入口。
- 移动端折叠菜单，复制求职简介，以及浏览器打印 / 保存 PDF。

项目文案依据个人提供的技能和项目类型整理。医学 AI 作为求职方向描述，未添加未经确认的临床成果或量化成绩。工作经历按要求填入示例公司、年份与职责，不代表真实履历；正式使用前请替换。

## 文件与维护

- `index.html`：正文、导航、SEO 描述。公开联系方式可添加到 `#contact-links`，并更新 `#contact-guidance`；目前提示从招聘或推荐原渠道联系。
- 工作经历位于 `index.html` 的 `#work` 区块：逐项替换 `.work-entry` 中的年份（含 `<time datetime>` 属性）、公司、职位、职责和技术标签，完成后移除「工作经历 · 示例」中的示例标记。
- `styles.css`：深绿色与薄荷绿视觉、响应式布局、打印样式。
- `script.js`：移动菜单、导航高亮、复制简介和打印。修改个人定位时同步更新 `intro` 文本。
- `skill-data.js`：技能目录，渲染时自动提取最终条目。
- `skill-tree.js`：Fibonacci 球面分布、透视投影、旋转、光点、深度排序和标签避让。
- `skill-tree.css`：技能球样式及首屏布局适配。
- `favicon.svg`：本地站点图标。

## 技能球

保留「光合生长」配色。47 个最终技能与经验节点始终加载在同一个三维球面上，约 42 秒旋转一圈。无需点击展开，无分页、筛选或点击暂停。

Canvas 绘制球面与光点，HTML 显示标签，无需 WebGL 或第三方运行时。节点按前后深度改变大小与亮度，文字始终正向；所有技能保留在无障碍列表中。系统设置减少动态效果时保持静止，离屏或标签页隐藏时暂停，返回后继续。页面其他区域提供静态技术与经验概览。

Google Fonts 提供可选英文字体，加载失败时使用系统字体；其他资源均在本地。

