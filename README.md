## 星球抖动修复

原算法每帧从投影锚点重新进行九轮标签碰撞推开。当两个标签相交时，推开方向及轴会突然变化；后续固定系数插值不能消除这种目标跳变。持续缩放文字还会引起字形重采样。

现在标签直接跟随连续投影轨迹，固定文字尺寸，通过平滑透明度表示前后层次；不再逐帧更改 left/top 或动态交换 z-index。前后标签交会时允许短暂重叠，后方标签降低亮度，完整技能另在静态技术能力区呈现。

球半径预留标签边界空间，避免位置硬限位导致速度突变。同时避免相同尺寸的 ResizeObserver 重复初始化；字体加载完成后重测尺寸。保留约 42 秒一圈的旋转、减少动态效果、离屏暂停和后台暂停。
